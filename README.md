# Word Garden

A teacher-led CVC word practice app for kindergarten.

**Open the app:** https://ashleymedeiros84.github.io/word-garden-cvc/

## Classroom practice

- **Build a word:** drag a letter into each sound box, or tap a letter and then a box. Check the word and blend it together.
- **Word chains:** change one letter at a time and read the new word.
- **Free play:** explore with movable letter tiles.
- **Teacher setup:** add custom three-letter CVC words and optionally hide the written target for listen-and-spell practice. Choose words containing spellings already taught.
- **Focus view:** simplify the screen for whole-class use.

Word audio uses browser speech synthesis. Teachers should model individual phonemes. Teacher settings are saved in the current browser; the app has no student accounts or score database.

An independent practice companion for use alongside UFLI Foundations. Not affiliated with or endorsed by UFLI; no official lesson sequence is assumed.

## Hosting

This static app uses `index.html`, `style.css`, and `app.js` with no build step. GitHub Pages serves the `main` branch from `/ (root)`. Google Fonts is optional; system fonts provide a fallback.
